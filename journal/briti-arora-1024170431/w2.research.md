### 🛠️ Work Done

- Researched interface patterns used in **map-based and booking platforms**.
- Studied the use of a **map + station list layout** for displaying nearby charging stations.
- Planned filters for **connector type, distance, availability and price**.
- Researched responsive layouts using **Bootstrap 5** for desktop, tablet and mobile screens.
- Worked on simplifying the booking flow into **station selection → slot selection → confirmation**.
- Planned the visual hierarchy so that **availability, price and booking actions** are immediately noticeable.
